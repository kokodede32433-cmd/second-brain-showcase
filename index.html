Из чего состоит

Три части, которые работают вместе

Хаб

Локальный сайт со сводкой по всем проектам. Сам находит репозитории и планы задач в выбранных папках.

  • несохранённая и неотправленная работа
  • карта задачи и путь до цели
  • страховочные копии без участия человека

Мозг

Хранилище заметок в обычных Markdown-файлах. Связи между записями видны на карте, поиск понимает смысл, а не только слова.

  • входящие с разбором: тип, проект, теги
  • карта знаний со связями
  • личные записи закрыты от агентов

Агенты

Claude Code, Codex и другие подключаются к Мозгу и получают память проекта: суть, стадию, следующий шаг и журнал.

  • читают и ищут по смыслу
  • записывают, что сделано
  • каждое обращение к личному журналируется

Как работает Хаб

Что хаб видит в ваших проектах и что с этим делает

Хаб ничего не меняет сам. Он читает папки и git, раскладывает находки по смыслу и предлагает действие, которое подтверждает человек.

Как это устроено

От мысли в телефоне до агента, который в курсе

Записали

Мысль приходит из Telegram, из хаба или от агента. Она попадает во «Входящие» как есть.

Разобрали

Недорогая модель предлагает тип, проект и теги. Человек подтверждает одним нажатием или правит.

Связали

Запись встаёт на карту рядом с проектом. Связи «содержит», «основа для», «продолжает» видны стрелками.

Использовали

Агент перед работой читает карточку проекта, а после — записывает, что сделал и какой шаг следующий.

Почему этому можно доверять

Всё лежит на вашем компьютере

  • Только локально. Хаб и Мозг слушают адрес 127.0.0.1. Из сети их не видно.
  • Обычные файлы. Заметки — это Markdown в папке. Их можно открыть любым редактором и забрать с собой.
  • Смысловой поиск без облака. Модель для поиска работает на этом же компьютере.
  • Личное закрыто. Агент видит личные записи только по прямой просьбе человека, и каждый такой случай остаётся в журнале.
  • Действия подтверждает человек. Коммит, отправку и удаление хаб сам не делает.
Установка

Две команды

# хаб: карты и git всех проектов
python3 hub/hub.py --install

# Мозг: память и подключение агентов
uv run second-brain install

# дальше всё открывается в браузере
http://localhost:7777

Нужны macOS, Python 3.12 и uv. Хаб работает также на Windows и Linux.
